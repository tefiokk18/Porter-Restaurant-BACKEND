# 🍔 Porter Restaurant - Backend

## 📝 Descripción del proyecto
Este es el servidor de la aplicación **Porter Restaurant**, desarrollado como proyecto final para **RollingCode School**. 
La API permite gestionar usuarios (con diferentes roles de acceso) y un sistema de reservas de mesas con validaciones en tiempo real para garantizar la integridad de los datos.

## 🚀 Tecnologías utilizadas
* **Node.js** & **Express**
* **MongoDB Atlas** (Mongoose)
* **JSON Web Token (JWT)** para autenticación
* **Bcryptjs** para encriptación de contraseñas
* **Express-validator** para validación de inputs
* **CORS** & **Dotenv**
